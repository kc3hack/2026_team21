# Development Guide

## 必要なもの

- Node.js: v24.13.1 ([.node-version](../.node-version) を参照)
- pnpm: v10.29.3

### Node.js のインストール

Node.js をお好みの方法でインストールしてください。
バージョンは[.node-version](../.node-version) ファイルに記載されているものを使用してください。

### pnpm のインストール

お好みの方法で pnpm をインストールしてください。

```
$ corepack enable
$ corepack use pnpm@latest-10
```

## 起動

```
$ pnpm dev
```
